# Nikita-2 Mail

Nikita-2 Mail is a personal technical application used to let the digital assistant Nikita-2 read messages from its own Gmail account through the Gmail API.

The application is private-use only and is not offered as a public service.

## Google API usage

The application requests read-only Gmail access:

`https://www.googleapis.com/auth/gmail.readonly`

It does not send, modify, or delete email.
