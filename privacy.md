# Privacy Policy — Nikita-2 Mail

Last updated: 1 October 2026

Nikita-2 Mail is a private personal application used by the owner of the Google account connected to the application.

## Data accessed

The application may read Gmail messages only after explicit authorization by the Google account owner using the scope:

`https://www.googleapis.com/auth/gmail.readonly`

The application does not request permission to send, modify, or delete Gmail messages.

## Data use

Email data is used only to provide the private Nikita-2 assistant with access to its own mailbox and to answer requests based on that mailbox.

## Data sharing

Gmail data is not sold, rented, shared for advertising, or made available to unrelated third parties.

## Storage and security

OAuth credentials and tokens are stored privately on the owner's server and are not published on this website. Passwords, API keys, tokens, private email contents, and server addresses are not published here.

## Revoking access

The Google account owner can revoke the application's access at any time from Google Account security settings.

## Contact

For questions about this application, use the Google account associated with Nikita-2 Mail.
